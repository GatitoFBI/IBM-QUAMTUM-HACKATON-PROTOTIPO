# Informe y datos de ruido de Q-Niño

- [Informe PDF de 18 páginas](INFORME_RUIDO_GROVER.pdf).
- [Tablas y registros en Excel, 19 hojas](DATOS_RUIDO_GROVER.xlsx).
- [Entrega completa en ZIP](ENTREGA_RUIDO_GROVER.zip).
- [Informe en Markdown](INFORME_RUIDO_GROVER.md).
- [Validación de la entrega](VALIDACION_ENTREGA.json).

El ZIP contiene el informe, todas las tablas, los scripts y las pruebas con las carpetas `codigo/`, `evidencia/` y `figuras/`. Los comandos del informe y [LEEME.txt](LEEME.txt) describen esa estructura una vez descomprimida. El [manifiesto SHA-256](MANIFIESTO_SHA256.json) corresponde a los archivos de ese paquete.

En el repositorio, el código ejecutable y las pruebas están en la raíz; los [resultados principales](../REPORT.md) y la [comparación de compilación](../mitigation/README.md) conservan sus CSV y JSON por separado. Las copias de los tests del paquete se mantienen dentro del ZIP para que la ejecución normal de pytest no las recolecte otra vez.
