Guía Estratégica: QAP & Qiskit

Adaptación del reto NTT DATA / IBM Quantum para la gestión de riesgos y toma de decisiones ante el Fenómeno de El Niño en Perú.

1. Entendiendo el Problema (El Niño)

El reto original pide asignar 10 vuelos a 10 puertas minimizando distancias. Nosotros lo adaptamos a Logística Humanitaria:

Elementos (i, k)

Brigadas de ayuda (Médicos, Rescatistas, Logística).

Ubicaciones (j, l)

Zonas de riesgo o albergues (Piura, Tumbes, Chosica).

Flujo (Fik)

Sinergia entre brigadas. Si Médicos y Rescatistas deben coordinarse, su flujo es alto.

Distancia (Djl)

Tiempo de viaje entre zonas. (Puede aumentar si hay carreteras bloqueadas).

Objetivo: Minimizar el tiempo total de respuesta colocando las brigadas que más se coordinan en zonas cercanas.

2. Modelo Matemático (QAP)

Debemos definir variables binarias x_ij = 1 si la brigada i va a la zona j, y 0 en caso contrario.

min C(x) = Σ Σ Fik * Djl * xij * xkl

Sujeto a:

  • Asignación única: Cada brigada va a exactamente 1 zona. (Σj xij = 1)
  • Capacidad: Cada zona recibe exactamente 1 brigada. (Σi xij = 1)
Nota de penalización (QUBO): Las computadoras cuánticas no entienden de igualdades. Qiskit transforma estas restricciones en un Hamiltoniano añadiendo penalizaciones matemáticas (Multiplicador de Lagrange λ). Si una asignación rompe la regla, su energía (costo) aumenta drásticamente.

3. Implementación en Qiskit (Día 1: N=3)

Para el Día 1, el PDF sugiere usar N=3 o N=4. Aquí tienes el código base de Python usando QAOA.

import numpy as np
from qiskit_optimization import QuadraticProgram
from qiskit_algorithms import QAOA
from qiskit_algorithms.optimizers import COBYLA
from qiskit.primitives import StatevectorSampler
from qiskit_optimization.algorithms import MinimumEigenOptimizer

# 1. DATOS (N=3)
brigadas = ["Medica", "Logistica", "Rescate"]
zonas = ["Piura", "Chosica", "Tumbes"]

# Matriz de Flujo (Sinergia entre brigadas)
F = np.array([
    [0, 8, 2],  
    [8, 0, 5],  
    [2, 5, 0]   
])

# Matriz de Distancia (Tiempo en horas entre zonas)
D = np.array([
    [0, 12, 8],  
    [12, 0, 15], 
    [8, 15, 0]   
])

# 2. FORMULACIÓN MATEMÁTICA
qp = QuadraticProgram()
for i in range(len(brigadas)):
    for j in range(len(zonas)):
        qp.binary_var(name=f"x_{i}_{j}")
        
quadratic_terms = {}
for i in range(len(brigadas)):
    for k in range(len(brigadas)):
        if i == k: continue 
        for j in range(len(zonas)):
            for l in range(len(zonas)):
                if j == l: continue
                coef = F[i, k] * D[j, l]
                if coef != 0:
                    # Dividimos entre 2 para no contar doble (convención del PDF)
                    quadratic_terms[(f"x_{i}_{j}", f"x_{k}_{l}")] = coef / 2.0

qp.minimize(quadratic=quadratic_terms)

# Restricciones
for i in range(len(brigadas)):
    qp.linear_constraint(linear={f"x_{i}_{j}": 1 for j in range(len(zonas))}, sense="==", rhs=1)
for j in range(len(zonas)):
    qp.linear_constraint(linear={f"x_{i}_{j}": 1 for i in range(len(brigadas))}, sense="==", rhs=1)

# 3. EJECUCIÓN CON QAOA
sampler = StatevectorSampler()
optimizer = COBYLA(maxiter=100)
qaoa = QAOA(sampler=sampler, optimizer=optimizer, reps=2)
opt_qaoa = MinimumEigenOptimizer(qaoa)
resultado = opt_qaoa.solve(qp)

print(f"Costo Óptimo: {resultado.fval}")

4. Estrategia para Ganar el Hackathon

Etapa 1 (Día 1)

  • Haz un Baseline Clásico (Fuerza bruta para N=3, prueba las 6 combinaciones).
  • Corre tu script de Qiskit y asegúrate de que el costo coincida con el clásico.
  • Calcula el Gap (%): 100 * (C_qaoa - C_exacto) / C_exacto.

Etapa 2 (Día 1-2)

  • Si intentas N=10 (100 variables), QAOA local colapsará por memoria (se requieren \(2^{100}\) estados).
  • Solución: Usa Qiskit Optimization para plantear el problema, pero resuélvelo con un algoritmo clásico (Greedy) o un Warm Start (usar la solución clásica como punto de partida para QAOA).

Etapa 3 (Final: N≥14)

El PDF dice: "No es necesario enumerar todas las permutaciones ni simular un circuito de N² qubits". Para escalar:

  • Descomposición (Divide y vencerás): Separa las 14 zonas en 3 clústeres geográficos (Norte, Centro, Sur). Resuelve 3 problemas de N=5 con Qiskit y luego une.
  • Búsqueda Local: Usa Qiskit para resolver sub-problemas pequeños iterativamente, mejorando una solución inicial.
