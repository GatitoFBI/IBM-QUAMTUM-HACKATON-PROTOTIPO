¿Qué brigada va a qué zona?

Problema de asignación cuadrática (QAP) · El Niño costero

Elige las brigadas y las zonas, y ajusta las matrices: F = sinergia entre brigadas (cuánto deben coordinarse) y D = horas de viaje entre zonas. Al resolver, la fuerza bruta revisa las N! asignaciones y la búsqueda adaptativa de Grover busca el mínimo de C(p) = Σi<k Fik·Dp(i)p(k). Todo lo que cambies respecto a los datos cargados queda marcado en rosa y registrado en «Cambios».

      Cómo usamos Qiskit

      • QuantumCircuit con h, x y mcx: superposición y difusión 2|s⟩⟨s| − I.
      • DiagonalGate: oráculo de fase −1 sobre los índices que mejoran el umbral.

        Lo que esto es y lo que no es
          
      
        1. Oráculo idealizado. Para marcar estados, la simulación revisa la tabla de costos (N! evaluaciones). En hardware real el oráculo debe calcular el costo dentro del circuito con aritmética reversible. Por eso medimos consultas, no tiempo.
          2. 
      
        2. El tiempo simulado no es el de una QPU: simular 2qubits amplitudes crece exponencialmente.
          3. 
      
        3. La ventaja aparece desde N ≈ 7: para N ≤ 6 el presupuesto de Dürr–Høyer (constante 22,5) supera a N!.
          4. 
      
        4. Hoy no corre en hardware real a esta escala: el ruido impediría un oráculo tan profundo.
          5. 
      
        5. Datos de prueba: faltan las matrices qap10 para validar los óptimos de control (24, 32 y 340).
          6. 
      
        6. Versión honesta: sin la parada anticipada if not marcados: break; cada ejecución termina al agotar el presupuesto.
